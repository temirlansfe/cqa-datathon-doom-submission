# Freedom CQA

**Команда «Девушка Простушка»** · кейс Freedom Broker

Freedom CQA оценивает работу операторов в чатах и звонках на русском, казахском и английском. В карточке разговора видны итог, причины списаний и ссылки на реплики или фрагменты аудио.

Проверяющий может пересмотреть оценку по апелляции. Изменения правил сохраняются новой версией чек-листа, которую можно сравнить с предыдущей и применить к набору. Раздел «Инсайты» показывает повторяющиеся жалобы и разговоры, в которых они возникли.

## Запуск

В корне репозитория выполните команду Docker Compose.

```bash
docker compose up -d --build
```

Откройте [http://localhost:8090](http://localhost:8090). В разделе «Разговоры» загрузите [демо-набор](samples/demo_dialogs.json) и нажмите «Оценить новые». Без ключа Gemini доступен демонстрационный режим на эвристиках.

Для оценки с Gemini скопируйте [`.env.example`](.env.example) в `.env`, задайте `GEMINI_API_KEY` и `GEMINI_MODEL` и выполните `docker compose up -d`. Для импорта из API организаторов также задайте `DATASET_API_URL`.

## Расчёт оценки

Gemini возвращает ответы, объяснения и цитаты. Сервер сверяет цитаты с транскриптом, рассчитывает итог по весам чек-листа и перераспределяет вес неприменимых критериев (N/A). Грубые ошибки отмечаются отдельно.

Интерфейс на HTML, CSS и JavaScript рассчитан на адаптацию под Dynamics 365. API работает на FastAPI, данные хранятся в PostgreSQL.

Для DEV использован `gemini-3.8-flash`. Средняя расчётная стоимость на демостенде составила около **$0.01 за разговор**.
